---
title: 'Agent Integration — Overview'
description: 'How coding agents (Claude Code, Cursor, Codex, Copilot) consume Driftless as their shared memory layer.'
---

Driftless is not an agent — it's the context layer that agents read from and write to. Agents open a session, discover patterns, close the session, and the knowledge is lost. Driftless stores it in Cloud and surfaces it before anyone touches code.

## Two roles for agents

### Consumer agent

Reads context before editing to avoid re-discovering what the team already documented:

```bash
driftless sync
driftless context load --files "src/auth/guard.ts,src/auth/service.ts"
driftless graph file src/auth/guard.ts
```

### Producer agent

Persists discoveries after editing so the next agent doesn't have to start from scratch:

```bash
driftless context update b2b-guard --gotcha "Token expiry is 5min" --decision "Switched to RS256"
```

## The skill layer

The agent skill (`SKILL.md`) is the instruction set that teaches agents how to interact with Driftless. It's installed via `driftless install-skill` and injected into your repo's `AGENTS.md` and `CLAUDE.md`. The skill fetches from the public mirror at `driftless-sh/driftless-skill`, but the source of truth lives at `skills/driftless/` in the monorepo.

## What agents receive

When an agent queries Driftless through `context load` or `context get`, it receives:

| Payload | Description |
|---|---|
| **Stale topics** | What the team changed since the agent's last session |
| **Coverage** | What's documented vs. what's a gap (covered, partial, gap, critical-gap) |
| **Graph facts** | Entrypoints, guards, upstream/downstream dependencies |
| **Topic content** | What, how, decisions, gotchas, invariants |

## Architecture

Cloud is the source of truth. Local scans execute on the developer's machine. Agents consume context but never own it — context is a team asset, not session memory.

```text
Local scan → structural metadata → Cloud
Agent session → driftless sync → stale topics + coverage
Agent edits → driftless context update → Cloud stores discovery
Next agent → driftless sync → sees the previous agent's discovery
```
