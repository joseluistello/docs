These tools help an agent select the correct workspace and understand its current usage before it asks for more data or changes something.

## Workspace and usage tools

| Tool | Purpose |
| --- | --- |
| `workspaces` | List the workspaces the credential can access. |
| `usage` | Read the current plan, limits, renewal date, and commercial usage. |

Both tools require member-level access and accept a workspace only when the credential is authorized for it.

## Confirm before acting

Ask the agent to show the workspace name before a write, contact lookup, or campaign action. A credential for one workspace must never be used to read another workspace.
