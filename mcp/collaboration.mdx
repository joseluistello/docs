These tools resolve the identifiers the write tools expect and read workspace usage.

## Workspaces and usage

| Tool | Purpose | Returns |
| --- | --- | --- |
| `workspaces` | List the workspaces your credential can target | workspace slugs |
| `usage` | Read the monthly commercial allowance (requests + credits) | plan, limits, renewal |

Permissions: member-level reads. Availability: Available. Every tool accepts an optional `workspace` argument to target another workspace your credential is authorized for.

```text
workspaces → [ { slug, name, role } ]
```

## Deleted from the catalog

`members` (listing the workspace's members) and comments (`context_comment`) have
no MCP tool at all — their definitions and handlers were removed, not merely
hidden; a legacy `driftless_*` call now answers "Unknown tool". Both remain
available through the CLI and dashboard — listing members is not agent work.

## Permissions

| Scope | Covers |
| --- | --- |
| member (read) | `workspaces`, `usage` |
