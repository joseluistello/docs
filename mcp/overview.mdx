Brein exposes the current commercial capabilities of your workspace through MCP. An AI client can read the team's context, search market information, work with contacts, prepare campaigns, and run research.

For the complete public list, see the [MCP Tool Catalog](/mcp/catalog).

For client setup, start with [Connect your AI](/connect).

## What the client can work with

The public catalog currently contains **52 tools** across these areas:

| Area | What the agent can do | Reference |
| --- | --- | --- |
| Cerebro | Retrieve and update the team's offer, buyer profile, exclusions, geography, messages, and decisions. | [Cerebro tools](/mcp/knowledge) |
| Prospectos | Read contact records, update a contact, and file a revealed or imported person. | [CRM tools](/mcp/work) |
| Market | Search published suppliers, opportunities, awards, risks, and permits. | [Market tools](/mcp/overview#market-tools) |
| Campañas | Create, preview, approve, activate, pause, and measure email sequences. | [Campaign tools](/mcp/sequences) |
| Investigador | Start and inspect durable research. | [Research tools](/mcp/overview#research-tools) |
| Workspace | Read the workspaces and commercial usage available to the credential. | [Workspace tools](/mcp/collaboration) |
| Connections | Read from a provider that an administrator has already connected. | [Connection tools](/mcp/integrations) |

The client may read a broad list, but every call is checked against the authorized workspace and role.

## Market tools

Market tools answer bounded questions about published suppliers, opportunities, awards, risks, and permits. They return the result and its source context; they do not reveal contact coordinates or promise a complete market.

## Research tools

Research tools start and inspect Investigador runs. The result is a document for review, not an automatic conclusion. Current rules, prices, permits, and institutional details can remain explicit verification steps.

## Authentication

Use OAuth when the client supports it:

1. Add the Brein endpoint: `https://api.trybrein.com/mcp`
2. Open the client's authorization flow.
3. Sign in to Brein and select the workspace.
4. Approve the requested permissions.

An API key is available for supported integrations and self-hosted clients. Pass it through the client's secret store as `X-API-Key`; do not put the raw key in a repository.

A `401` means the credential is missing or invalid. A `403` means the credential is valid but is not allowed to perform the requested action in that workspace.

## A safe first request

Start with a read that has no external effect:

```text
Show the Brein workspaces I can use and the current commercial usage.
```

Then try a bounded search or a small piece of team context before asking the agent to change a contact or prepare a campaign. The agent must show the audience, price, or approval request before an action that spends credits or sends a message.

## Tool behavior

- Reads return a focused result and tell you when more pages are available.
- Contact details remain masked until the person chooses a selected lookup.
- CRM writes apply to the contact record named in the request.
- A campaign draft does not send itself; activation requires a separate confirmation.
- Clients may cache their tool list. Reconnect after a Brein tool change if a new tool is missing.
