---
title: 'MCP: Connections'
description: 'Read data from a provider that an administrator has already connected to Brein.'
---

MCP can expose bounded read tools for a provider that is already connected and ready. A typical connection may expose tools such as:

- `<provider>_records` — records from a synced provider model;
- `<provider>_document_content` — content from a connected document provider.

These tools do not connect, disconnect, or configure a provider. An administrator manages the connection in the Brein product. If a needed read tool is not listed, report the missing capability instead of inventing a new action.

Write tools are not synthesized into this MCP surface.
