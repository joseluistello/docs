Cerebro tools let an AI client read the team's commercial context before it acts and update that context when the team has a durable decision to keep.

Read [MCP and OAuth](/mcp/overview) first for authentication and workspace permissions.

## Read context

| Tool | Use it when you want to... | Main arguments |
| --- | --- | --- |
| `context_retrieve` | Find the most relevant context for a task or set of files. | `task`, `files`, `view`, `limit` |
| `context_get` | Read one document in full. | `topic`, `view` |

`context_retrieve` returns a short result by default. Fetch the full document only when you need it.

## Update context

| Tool | Use it when you want to... | Main arguments |
| --- | --- | --- |
| `context_create` | Create a document for a new durable decision. | `title`, `content`, `area` |
| `context_update` | Update an existing document. | `topic`, fields |

Documents are shared with the workspace by default. A write does not delete another document or publish a page to the web.

## Keep the context useful

A good Brein document explains:

- what the team sells;
- who the team wants to work with;
- what is out of scope;
- which geography and messages matter;
- what the team decided and why.
