title: 'MCP: CRM (Prospectos)'
description: 'Read bounded record pages and advance typed Records (accounts, opportunities and follow-up) through governed MCP tools.'
---

CRM is Brein's operational system of record: Prospectos (Collections/Records) hold accounts, opportunities and follow-up. The MCP tools are action-based, bounded by default, and use the same server contracts as the dashboard and CLI. Reads are member-level; lifecycle writes require `work:write`. The generic Collection schema/config CRUD and permanent purge have no MCP tool — configuring a pipeline is human work, and no agent tool deletes.

## Records

Use `collection_query` for bounded reads (status `ok` / `continue` / `incomplete`, never conclude coverage from one page). Before acting on a record, read the Collection's criterion with `context_get` on its `criterion_refs` — the criterion is what the team applies to those records.

| Tool | Main actions | Purpose |
| --- | --- | --- |
| `collection_query` | `query`, `get`, `aggregate` | Read bounded records with explicit projection, filtering, and continuation |
| `crm_record` | `add`, `update`, `history`, `bulk`, `schedule_activity` | Create or advance typed records; status must match the Collection lifecycle. Renamed from `collection_record` (MCP · 2) — reads (`list`/`get`) are no longer in its action enum, use `collection_query` |

```text
collection_query op:'query' collection_id:'<collection-id>' limit:25
  → { status:'ok'|'continue'|'incomplete', data:[ ... ], page_info:{ ... } }
```

## Deleted from the catalog

Collection schema configuration (`collection`), permanent purge
(`collection_purge`), record delete (`collection_record_delete`)
and the entity registry (`entity`) have no MCP tool at all — their
definitions and handlers were removed, not merely hidden; a legacy
`driftless_*` call now answers "Unknown tool". Schema configuration remains
a human dashboard/CLI surface; identity resolution happens server-side when a
record is saved.

## Permissions

| Scope or role | Covers |
| --- | --- |
| member read | Collection and Record reads, criterion context, history |
| `work:write` | Create and update Records; lifecycle writes |

MCP clients cache tool schemas per connector session. Reconnect the connector after an upgrade so removed or changed tools are reflected in the client.
