This page covers exactly what data Driftless holds and what it never touches. If something is stored, it's listed here. If it's not, that's stated plainly.

## Stored in Postgres (Supabase)

| Data | Description |
|---|---|
| **Workspace metadata** | Name, slug, Clerk organization ID |
| **Repo metadata** | Organization, repo name, system type, framework, scan summary |
| **Scanned components** | Type, name, file path, line number, metadata. No source code. |
| **Topic content** | What, how, decisions, gotchas, invariants, content body, tags |
| **Events** | Webhook events, watcher events, context events — commit hashes, authors, diff snippets |
| **Integration configs** | GitHub installation IDs, webhook secret hashes |
| **API key hashes** | SHA-256 hash only — never raw keys |
| **PR observations** | PR number, title, author, branch, files touched, matched topics, comment status |

## Never stored

- **Source code** — only file paths, line numbers, and structural metadata
- **Raw API keys** — only SHA-256 hash after creation
- **Raw GitHub webhook secrets** — verified then discarded
- **Raw GitHub App private keys** — read from environment variables, never persisted

## Encryption

| What | Method |
|---|---|
| API keys | SHA-256 hash (one-way) |
| Webhook secrets, tokens | AES-256-GCM (two-way, reversible) |

See the [Encryption](/security/encryption) page for full details on the AES-256-GCM implementation.

## Transit

All API communication is over HTTPS. No unencrypted endpoints exist.

## Infrastructure

| Component | Hosting |
|---|---|
| **API** | Render |
| **Dashboard** | Vercel |
| **Mintlify Docs** | Mintlify (deploys from `54.242.90.151`) |
| **Database** | Supabase (Postgres) |

## Backups

Supabase handles Postgres backups automatically. No additional backup infrastructure is maintained.

## Deletion

### Repo deletion

`DELETE /workspaces/:slug/repos/:id` fully cleans up:

- Removes all components, events, and PR observations for that repo
- Removes the repo from all topics' `where_repos`
- Orphans topics that no longer match any repo

### Workspace deletion

Not self-serve during beta. Contact Driftless to request full workspace deletion. Everything tied to the workspace — repos, components, topics, events, integration configs — is purged.
