## v0.2.2

*May 2026*

- Content persistence — topics store full Markdown bodies
- File anchoring — `context sync --file` links docs to code
- TypeORM entities updated to match

## v0.2.0

*May 2026*

Big shift: from scanner + rules engine → context delivery + knowledge graph.

- **Flexible Topics** — Markdown documents with metadata (content, tags, kind, status, origin)
- **Typed relations** — `depends_on`, `relates_to`, `supersedes`, `blocks`, `implements`, `risk_for`
- **Wiki-links** — `[[slug]]` cross-references parsed into bidirectional graph edges
- **Cross-repo context** — topics accumulate repos automatically on `context update`
- **Honest auth detection** — reads `@UseGuards`, `APP_GUARD`, Clerk `auth()` instead of assuming public
- **Secrets encryption** — AES-256-GCM for all API keys and tokens
- **Agent self-healing** — `install-skill` replaces managed block in-place
- **Removed** — SEMANTIC rules, POST /scan violations, `driftless scan --diff`, rules/violations dashboard, intents API

## v0.1.x — The Foundation Era

*January–May 2026*

### Scanner maturity

- **0.1.48** — Honest auth: APP_GUARD detection, never assert "public"
- **0.1.49** — Per-file byte-cap circuit breaker (no OOM on large repos)
- **0.1.65** — Init UX: colored banner, `--framework auto|nestjs|nextjs`, `--suggest` opt-in
- **0.1.66** — Multi-pattern anchoring (`--add-pattern`, `--remove-pattern`) and real `--help`
- **0.1.67** — `[[slug]]` wiki-links — first step toward the knowledge graph
- **0.1.68–0.1.72** — Next.js Fase 1 + 2: App Router extractor, React component detection, Clerk auth inference

### Cross-repo context

- **0.1.62** — Surface cross-repo references in `context get`
- **0.1.63** — Explicit `context link` + visible auto-link

### Dogfood-driven fixes

- AGENTS.md skill block self-heals (was frozen forever)
- Skill REFERENCES installed alongside SKILL.md
- `resolveRepo` no longer collapses to `no_workspace` under load
- Init shows components for branched repos with `--src`
- `--decision` appends instead of overwriting
- GitHub App shows correct installation state

## v0.0.x — Genesis

*January 2026*

Monorepo scaffolded with Turborepo, NestJS API, TypeORM entities, and GitHub webhook handler. Scanner extracted NestJS endpoints, guards, services, and modules from AST (ts-morph). CLI shipped with `login`, `init`, `scan`, and `context`. First dogfood run on `profile_nippy_ms` detected 155 endpoints and 15 guards.
