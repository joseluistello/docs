---
title: 'Insertar en tu web'
description: 'Coloca un Formulario dentro de tu propia página con un snippet y tres modos de mostrar.'
---

La inserción carga el formulario público en un `iframe` y ajusta su altura por su cuenta. Pega este snippet donde quieras que aparezca el formulario:

```html
<script src="https://trybrein.com/embed.js" async></script>
<div data-brein-form="frm_AbC123dEf4" data-mode="inline"></div>
```

`data-brein-form` lleva el id público del formulario (el mismo de su enlace) y `data-mode` es `inline`, `popup` o `slide`.

## Los tres modos

| Modo | Qué hace |
| --- | --- |
| `inline` | El formulario aparece en su lugar, dentro del flujo de la página. |
| `popup` | Un botón abre el formulario en una ventana centrada. Cambia el texto del botón con `data-button-text`. |
| `slide` | El formulario aparece en una esquina, con un botón para cerrar. |

Para el modo `popup` también puedes abrirlo desde tu propio código con `window.BreinForms.open("frm_AbC123dEf4")`.

## Dominios permitidos

Si pones **Dominios permitidos** en el formulario, solo esos sitios pueden mostrar un formulario insertado; deja la lista vacía y cualquiera puede. Escribe un dominio por línea; una entrada `*.dominio.mx` acepta sus subdominios. Un envío desde el navegador de un sitio que no está permitido se rechaza con `403`.

## El evento `brein:submitted`

Cuando se acepta una respuesta, la inserción dispara un evento `brein:submitted` en el elemento del formulario, con `detail.formId` y `detail.responseId`. Úsalo para contar una conversión, por ejemplo en Google Analytics:

```html
<script>
  document.addEventListener('brein:submitted', function (event) {
    if (typeof gtag === 'function') {
      gtag('event', 'generate_lead', { form_id: event.detail.formId })
    }
  })
</script>
```
