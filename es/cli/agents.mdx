La familia `agent` configura Librarian. Agrega `--json` para salida de máquina.

## Configuración

| Comando | Descripción |
|---|---|
| `agent config [--show]` | Imprime la config actual. |
| `agent config --set <key>=<value>` | Setea una key de config (repetible). |

Keys seteables en `agent config --set`: `librarian` y `librarian_autovouch`.

No hay ajuste de proveedor, de modelo ni de API key. Driftless opera y paga la inferencia sobre la que corren los agentes, y elige el modelo en cada turno; `agent config --set model=…` y `--set opencode_key=…` se rechazan en lugar de ignorarse, para que un script viejo falle de forma visible en vez de aparentar que funcionó.

```bash
driftless agent config --set librarian=true
driftless agent config --show
```

Librarian está apagado hasta que su toggle está encendido.

## Permisos

Configurar Librarian es una acción de miembro del workspace desde la CLI.
