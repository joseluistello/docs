Aquí viven dos cosas: la familia `agent` configura e inspecciona los agentes del lado del servidor ([Auditor, Architect, Librarian](/es/agents/agentic-layer)), y los comandos `hook` / `hooks` gestionan el hook local de [auto-pull](/es/concepts/automations). No están relacionados: `agent` habla con el servidor, `hooks` edita un archivo local. Agrega `--json` a cualquier comando `agent` para salida de máquina.

## Agent runs y config

Los agentes corren de forma automática del lado del servidor; la CLI los inspecciona y configura. No hay un comando para disparar una corrida a mano (fue retirado).

| Comando | Descripción |
|---|---|
| `agent runs [--limit <n>]` | Corridas recientes (id, agente, status, hora). |
| `agent run <id>` | Una corrida con su trace completo. |
| `agent config [--show]` | Imprime la config actual. Las keys secretas nunca se muestran. |
| `agent config --set <key>=<value>` | Setea una key de config (repetible). |
| `agent usage [--days <n>]` | Resumen de tokens y costo. |
| `agent stats` | Estadísticas de aceptación de propuestas. |
| `agent models` | El catálogo de modelos BYOM. |

## Configuración BYOM

Keys seteables en `agent config --set`: `opencode_key` (la key de bring-your-own-model, de solo escritura), `model` (una lista de prioridad separada por comas de `provider/model`; el runner rota ante un error de rate-limit o de crédito), y los toggles `auditor`, `architect`, `librarian` y `librarian_autovouch`.

```bash
driftless agent config --set opencode_key=oc_xxx --set model="opencode/claude-sonnet-4-6"
driftless agent config --set auditor=true --set architect=true
driftless agent config --show    # la key se redacta
```

Cada agente está apagado hasta que su toggle está encendido y hay una key de modelo configurada; si no, una corrida registra un `no_op`.

## Hooks (auto-pull)

El hook de auto-pull es una función local de Claude Code, apagada por defecto. Dos comandos lo gestionan, y son distintos:

| Comando | Descripción |
|---|---|
| `hook <pre-edit\|post-edit\|stop\|sync>` | El pegamento en runtime que Claude Code invoca. Nunca lo corres a mano. |
| `hooks enable` | Instala las entradas del hook en `.claude/settings.json` (PreToolUse, PostToolUse, Stop). |
| `hooks disable` | Quita esas entradas de esta máquina. |

Instalar el hook queda inerte hasta que un admin del workspace enciende el toggle `auto_pull_context` en el dashboard. Solo los topics de Knowledge (`reviewed`) se inyectan.

```bash
driftless install-skill    # instala el hook, inerte
driftless hooks disable    # quítalo de esta máquina
```

## Permisos

Leer las corridas de agentes y setear la config BYOM son acciones de miembro del workspace desde la CLI. La superficie de agent-runs no es alcanzable por OAuth/MCP (las corridas de agentes gastan inferencia de modelo); la superficie MCP solo expone `driftless_agent_stats`.
