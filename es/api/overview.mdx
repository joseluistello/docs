URL base:

```text
https://api.driftless.icu/api/v1
```

## Autenticación

La mayoría de los endpoints requieren una sesión de Clerk desde el dashboard o una API key desde la CLI.

```bash
curl https://api.driftless.icu/api/v1/workspaces/acme/repos \
  -H "x-api-key: drift_your_api_key_here"
```

<Warning>
  Trata las API keys como secretos. Driftless guarda las keys cifradas y solo muestra el valor en crudo una vez, al momento de crearlas.
</Warning>

## Endpoints públicos

Estos endpoints no requieren autenticación:

| Método | Ruta | Propósito |
|---|---|---|
| `GET` | `/health` | Chequeo de salud en tiempo de ejecución |
| `GET` | `/version` | Versión de la API y metadatos del despliegue |
| `POST` | `/workspaces` | Arranque de workspace |
| `GET` | `/blog/posts` | Índice público del blog |
| `GET` | `/blog/posts/:slug` | Entrada pública del blog |
| `POST` | `/webhooks/clerk` | Receptor de webhooks de Clerk |

## Autenticación y API keys

| Método | Ruta | Propósito |
|---|---|---|
| `GET` | `/me` | Identidad actual y contexto del workspace |
| `POST` | `/workspaces/:slug/api-keys` | Crea una API key para ese workspace |
| `GET` | `/workspaces/:slug/api-keys` | Lista las API keys de un workspace |
| `DELETE` | `/workspaces/:slug/api-keys/:id` | Revoca una API key |

## Uso comercial

| Método | Ruta | Propósito |
|---|---|---|
| `GET` | `/workspaces/:slug/commercial-usage` | Consulta plan, solicitudes, créditos, renovación, investigación promocional y la acción para hablar con ventas |

Explorar incluye 10 solicitudes de inteligencia comercial y 25 créditos por mes
calendario, con hasta 5 resultados entregados por solicitud. Founder cuesta USD
29 al mes e incluye 50 solicitudes, 250 créditos y hasta 10 resultados por
solicitud. Cada espacio puede canjear una investigación profunda sin consumir
ninguno de los dos saldos. Una solicitud de
primer nivel cuenta una sola vez; las llamadas internas no. Cerebro, CRM, la
navegación y la consulta de capacidades son gratuitas. Las respuestas exitosas
de market data incluyen `commercial_usage`. Cuando se agota el saldo, la API
devuelve HTTP `402` con un código `COMMERCIAL_*` estable, `retryable: false`, el
estado actual en `usage` y `next_action.kind: "contact_sales"`.

## OAuth

Endpoints OAuth 2.0 para aplicaciones cliente de MCP:

| Método | Ruta | Propósito |
|---|---|---|
| `GET` | `/oauth/authorize` | Pantalla de consentimiento de autorización |
| `POST` | `/oauth/token` | Intercambia el código de autorización por un token de acceso |
| `POST` | `/oauth/register` | Registra un cliente OAuth |
| `POST` | `/oauth/revoke` | Revoca un token de acceso |
