description: 'La API REST autenticada para crear software que trabaje con un workspace de Brein.'
---

URL base:

```text
https://api.trybrein.com/api/v1
```

Usa la API REST cuando tu software necesite leer o cambiar directamente un workspace de Brein. Para un cliente de IA, empieza por [MCP y OAuth](/es/mcp/overview).

## Autenticación

Envía una API key con scope en el header `x-api-key`:

```bash
curl https://api.trybrein.com/api/v1/me \
  -H "x-api-key: <your-api-key>"
```

Una key faltante o inválida devuelve `401`. Una key válida sin permiso para el workspace o la acción devuelve `403`.

Conserva las keys en tu gestor de secretos. Nunca las commitees ni las muestres en output para clientes.

## Recursos principales

| Recurso | Ruta base | Úsalo para |
| --- | --- | --- |
| Workspace y uso | `/workspaces/:slug` | Leer detalles del workspace, acceso del equipo y uso comercial. |
| Cerebro | `/workspaces/:slug/documents/*` | Leer y actualizar documentos en carpetas. |
| Prospectos | `/workspaces/:slug/collections/*` | Leer y actualizar contactos. |
| Empresas y personas | `/workspaces/:slug/radar/*` | Buscar empresas, revisar personas enmascaradas y trabajar con contactos adquiridos. |
| Información de mercado | `/workspaces/:slug/market-data/*` | Ejecutar operaciones de sólo lectura sobre proveedores, oportunidades, adjudicaciones, riesgos y permisos. |
| Research | `/workspaces/:slug/research/*` | Iniciar, inspeccionar y cancelar corridas de Investigador. |
| Campañas | `/workspaces/:slug/email-campaigns/*` | Preparar, revisar, activar, pausar y medir secuencias. |
| Conexiones | `/workspaces/:slug/integrations/*` | Listar y administrar conexiones aprobadas. |

Cada ruta de workspace está limitada al workspace de la URL. No asumas que una ruta de un workspace puede usarse con las credenciales de otro.

## Uso y acciones

Las lecturas y las acciones de contacto tienen reglas de costo diferentes. Una respuesta exitosa puede incluir el estado de uso actual. Si se agota una allowance, la API devuelve un `402` accionable en vez de continuar silenciosamente.

Buscar un contacto es separado de guardar un contacto. Crear una campaña es separado de activarla. Una campaña no se envía hasta que la confirmación humana requerida termina correctamente.
