## Integraciones

| Método | Ruta | Propósito |
|---|---|---|
| `GET` | `/workspaces/:slug/integrations` | Lista las integraciones |
| `POST` | `/workspaces/:slug/integrations` | Crea o conecta una integración |
| `DELETE` | `/workspaces/:slug/integrations/:id` | Elimina una integración |
