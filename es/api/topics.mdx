---
title: 'Topics y documentos de Cerebro'
description: 'Rutas actuales de documentos de Cerebro y la superficie Topics retirada.'
---

Cerebro es el modelo actual de documentos para el cliente. El dashboard y la API actual usan documentos markdown dentro de carpetas. La API antigua de Topics sigue montada por compatibilidad, pero su lenguaje de gobernanza y grafo no es el flujo actual del cliente.

## Rutas actuales de documentos de Cerebro

| Método | Ruta | Propósito |
|---|---|---|
| `GET` | `/workspaces/:slug/documents/tree` | Explora el árbol de documentos. |
| `GET` | `/workspaces/:slug/documents/file` | Lee un documento por carpeta/ruta. |
| `PUT` | `/workspaces/:slug/documents/file` | Crea o reemplaza un documento. |
| `GET` | `/workspaces/:slug/documents/search` | Busca contenido de documentos en el workspace. |

Un documento nace compartido con el workspace. No hay una cola de aprobación Note → Knowledge en el modelo actual. Para cambiar contexto comercial durable, lee el documento actual y reescribe el cuerpo consolidado.

## Rutas Topics de compatibilidad

Estas rutas siguen disponibles para clientes técnicos existentes:

| Método | Ruta | Propósito |
|---|---|---|
| `GET` | `/workspaces/:slug/topics` | Lista topics. |
| `POST` | `/workspaces/:slug/topics` | Crea un registro con forma de topic. |
| `GET` | `/workspaces/:slug/topics/:topic` | Lee un topic. |
| `PATCH` | `/workspaces/:slug/topics/:topic` | Actualiza un topic. |
| `DELETE` | `/workspaces/:slug/topics/:topic` | Elimina un topic mediante la API de compatibilidad. |

Los campos `status`, `trust`, proposal y governance pueden permanecer en respuestas históricas, pero no crean un flujo activo de aprobación. No construyas una integración nueva de cliente sobre ellos.

## Búsqueda y coincidencia de rutas

La superficie Topics conserva búsqueda acotada y coincidencia de rutas:

- `GET /workspaces/:slug/topics/search`
- `POST /workspaces/:slug/topics/match-files`
- `GET /workspaces/:slug/topics?stale=true|false`

Las anclas de rutas siguen siendo útiles para equipos de software, pero no son el centro del producto comercial.

## Gobernanza retirada

Los verbos|Note → Knowledge y el ciclo de proposals están retirados. Rutas como `propose`, `approve`, `reject`, proposals y merge son no-ops de compatibilidad donde todavía existen; no mueven un documento por estados de revisión. Usa la ruta de actualización de documentos o los comandos de contexto de la CLI.

El grafo de topics, las relaciones manuales y el chrome de gobernanza para clientes no forman parte del flujo actual de Cerebro. Pueden permanecer en almacenamiento o superficies técnicas de compatibilidad para consumidores que no han migrado.

## Visibilidad y compartir

La visibilidad de un documento en el workspace y el compartir público son separados del modelo retirado de gobernanza. La CLI y el dashboard controlan el sharing humano; el catálogo MCP público no expone borrado de topics, publicación, grafo, relaciones, comentarios ni proposals.
