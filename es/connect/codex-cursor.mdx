---
title: '¿Cómo conecto Brein a Codex o Cursor?'
description: 'Conecta Brein a Codex o a Cursor desde sus ajustes y úsalo mientras trabajas.'
---

Si trabajas en Codex o en Cursor, también puedes hablar con Brein ahí: pedir una lista de clientes mientras programas, o revisar tu pipeline sin salir de tu herramienta.

Brein se conecta con la misma dirección en todos los clientes:

```text
https://api.trybrein.com/mcp
```

## Codex

Sirve igual en la app de Codex y en su extensión del editor: las dos comparten la misma configuración.

<Steps>
  <Step title="Abre los servidores MCP">
    En la app de Codex: **Settings → MCP servers**. En la extensión del editor: el engrane y luego **MCP servers**.

    {/* CAPTURA: Codex, Settings → MCP servers */}
  </Step>
  <Step title="Agrega Brein">
    Toca **Add server**:

    - **Nombre:** `brein`
    - **Tipo:** Streamable HTTP
    - **URL:** `https://api.trybrein.com/mcp`

    Guarda y toca **Restart** (en la extensión, **Restart extension**).
  </Step>
  <Step title="Entra a Brein">
    En la lista, Brein aparece marcado como que necesita inicio de sesión. Toca **Authenticate**: se abre el navegador, entras a Brein, eliges tu espacio y apruebas.

    {/* CAPTURA: pantalla de aprobación de Brein */}
  </Step>
  <Step title="Empieza una conversación nueva">
    Abre una conversación nueva para que Codex cargue las herramientas de Brein.
  </Step>
</Steps>

<Accordion title="¿Usas Codex en la terminal?">
  Agrega Brein con `codex mcp add brein --url https://api.trybrein.com/mcp` y luego entra con `codex mcp login brein`. La configuración es la misma que usan la app y la extensión.
</Accordion>

## Cursor

<Steps>
  <Step title="Abre los ajustes de MCP">
    En los ajustes de Cursor, busca la sección de **MCP** y elige agregar un servidor nuevo. El nombre del menú cambia entre versiones; si no lo encuentras, busca «MCP» en los ajustes.

    {/* CAPTURA: Cursor, ajustes de MCP */}
  </Step>
  <Step title="Pega la configuración">
    ```json
    {
      "mcpServers": {
        "brein": {
          "url": "https://api.trybrein.com/mcp"
        }
      }
    }
    ```
  </Step>
  <Step title="Conéctate">
    Brein aparece como que necesita inicio de sesión. Toca **Connect**, entra a Brein, elige tu espacio y aprueba.
  </Step>
  <Step title="Comprueba">
    Brein debe verse con un punto verde y sus herramientas listadas.
  </Step>
</Steps>
