Brein está disponible mediante un único servidor MCP remoto:

```text
https://api.trybrein.com/mcp
```

Tu cliente de IA elige el modelo. Brein aporta los datos y las acciones comerciales que pertenecen al workspace que autorices.

Estas son superficies de cliente, no una afirmación de partnership comercial. El cliente controla su modelo y su cuenta. Brein controla el acceso al workspace, las herramientas disponibles, el uso y las confirmaciones.

## ChatGPT

En la app de Brein o en la configuración de conectores de ChatGPT, agrega:

```text
https://api.trybrein.com/mcp
```

Completa la autorización de Brein y selecciona el workspace que quieres que use el agente.

Empieza con una lectura pequeña:

```text
Muestra los workspaces de Brein que puedo usar y el uso comercial actual.
```

No pidas al agente que revele un contacto o active una campaña antes de que te haya mostrado la audiencia, el precio o la solicitud de aprobación.

## Claude

Agrega el endpoint como conector MCP remoto:

```text
https://api.trybrein.com/mcp
```

Usa OAuth cuando Claude ofrezca el flujo del conector. Si tu organización sólo soporta autenticación por headers, usa el fallback con API key que aparece abajo.

Después de iniciar sesión, selecciona el workspace autorizado antes de pedir acciones de mercado, CRM o campañas.

## OpenCode

Agrega Brein globalmente:

```bash
opencode mcp add brein --global \
  --url https://api.trybrein.com/mcp
```

Dentro de OpenCode, corre:

```text
/mcps
```

Selecciona Brein y completa la autorización del navegador. Cuando el estado sea `connected`, el agente descubrirá las herramientas disponibles.

También puedes configurarlo en `opencode.jsonc`:

```jsonc
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "servers": {
      "brein": {
        "type": "remote",
        "url": "https://api.trybrein.com/mcp"
      }
    }
  }
}
```

Las credenciales OAuth quedan fuera de la configuración del proyecto. OpenCode puede agregar el prefijo local `brein_` a los nombres de las herramientas; ese prefijo no es otra API de Brein.

## Otros clientes MCP

El setup es el mismo para un cliente MCP remoto estándar:

1. Agrega un servidor remoto.
2. Pega la URL de Brein.
3. Completa OAuth o usa una API key con scope si OAuth no está disponible.
4. Selecciona el workspace autorizado.
5. Verifica la conexión con una lectura pequeña.

El cliente puede usar cualquier modelo que ya soporte. Brein no requiere un provider de modelos concreto.

## Hermes y OpenClaw

Para un cliente que soporta OAuth MCP remoto, usa el flujo normal de autorización de Brein. Para un cliente que requiere headers, conserva la key en el almacén de secretos o variables de entorno del cliente:

```jsonc
{
  "mcp": {
    "servers": {
      "brein": {
        "type": "remote",
        "url": "https://api.trybrein.com/mcp",
        "oauth": false,
        "headers": {
          "X-API-Key": "${BREIN_API_KEY}"
        }
      }
    }
  }
}
```

No commitees la key cruda a un repositorio. Una key sólo da acceso a los workspaces y roles para los que fue autorizada.

## Qué puede hacer la conexión

Un cliente conectado puede trabajar con el workspace de Brein:

- leer y actualizar documentos de Cerebro;
- buscar información de mercado publicada;
- encontrar empresas y personas enmascaradas;
- cotizar y revelar personas seleccionadas;
- leer y actualizar contactos en Prospectos;
- preparar y revisar campañas;
- consultar el uso comercial;
- ejecutar investigación durable.

Leer no es lo mismo que actuar. Las búsquedas de contactos, escrituras en el CRM y activaciones de campañas tienen sus propios requisitos de costo, permisos y confirmación.

## Troubleshooting

| Síntoma | Qué revisar |
|---|---|
| `401 Unauthorized` | Reconecta OAuth o reemplaza la API key con scope. |
| `403 Forbidden` | Revisa membresía, rol y permisos del cliente. |
| Faltan herramientas | Reconecta el cliente; los clientes actualizan su lista por sesión. |
| Workspace equivocado | Cambia el workspace activo o autoriza otra vez. |
| Una acción de contacto es rechazada | Corre el flujo actual de precio y confirmación. |

Para el contrato completo de herramientas, consulta [MCP y OAuth](/es/mcp/overview). Para software que no sea un cliente de IA, usa la [API REST](/es/api/overview).
