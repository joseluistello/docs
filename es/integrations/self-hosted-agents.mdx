OpenClaw y Hermes Agent son agentes self-hosted que pueden tener acceso al shell, skills y soporte MCP. Brein ofrece dos puertas separadas:

- **CLI + skill de ingeniería** para un workflow de repositorio: leer el contexto relevante de Cerebro antes de editar y escribir un documento limpio después de aprender algo durable.
- **MCP remoto** para un cliente de IA que debe trabajar con las capacidades comerciales gobernadas de Brein.

Los nombres de CLI y paquete siguen siendo contratos de compatibilidad `driftless`. El endpoint MCP público usa nombres neutrales.

## Datos de conexión compartidos

| | Valor |
|---|---|
| MCP endpoint | `https://api.trybrein.com/mcp` |
| Autenticación MCP | `X-API-Key: drift_…` u OAuth para clientes soportados |
| Paquete CLI | `@driftless-sh/cli` |
| API key | Dashboard de Brein → **Settings → API Keys** |

Una key está acotada a los workspaces que autorizó. No se convierte en una super key. Si eliminas a una persona del workspace, su acceso a ese workspace se revoca mediante la frontera normal de autorización.

## CLI + skill

Instala y autentica en el host que ejecuta el agente:

```bash
pnpm add -g @driftless-sh/cli
# o
npm install -g @driftless-sh/cli
driftless login --key drift_your_api_key_here
```

Desde el repositorio o raíz del workspace:

```bash
driftless install-skill
```

El skill enseña el loop de contexto de ingeniería. No autoriza al agente a enviar emails, revelar contactos, gastar créditos ni tomar una decisión CRM importante sin la autorización del servidor.

## MCP remoto

Para OpenClaw:

```bash
openclaw mcp add driftless \
  --url https://api.trybrein.com/mcp \
  --transport streamable-http \
  --header X-API-Key:drift_your_api_key_here
```

Para Hermes, agrega el endpoint bajo `mcp_servers` en `~/.hermes/config.yaml`:

```yaml
mcp_servers:
  driftless:
    url: "https://api.trybrein.com/mcp"
    headers:
      X-API-Key: "drift_your_api_key_here"
    tools:
      resources: false
      prompts: false
```

Usa los nombres neutrales actuales, como `context_retrieve`, `context_get`, `collection_query`, `crm_record`, `people_search` y `sequence_activate`. No construyas una integración nueva alrededor de tools retiradas como `driftless_context_search`, `driftless_collection`, `driftless_tags` o `driftless_areas`.

## Verifica la conexión

1. Ejecuta una lectura acotada como `context_retrieve` o `collection_query`.
2. Confirma que la respuesta pertenece al workspace correcto.
3. Si necesitas una escritura, usa el contrato actual y la autorización explícita que indique el resultado.
4. Reconecta o recarga MCP después de un cambio de schema; los clientes cachean definiciones por sesión.

Un `401` significa que la API key o token OAuth no llegó a Brein. Un `403` significa que el caller está autenticado pero no tiene el scope o rol requerido.
