---
title: 'MCP: Conexiones'
description: 'Lee datos de un provider que un administrador ya conectó a Brein.'
---

MCP puede exponer herramientas de lectura acotadas para un provider que ya está conectado y listo. Una conexión típica puede exponer herramientas como:

- `<provider>_records` — registros de un modelo sincronizado del provider;
- `<provider>_document_content` — contenido de un provider de documentos conectado.

Estas herramientas no conectan, desconectan ni configuran un provider. Un administrador gestiona la conexión en el producto Brein. Si una herramienta de lectura necesaria no aparece, reporta la capability faltante en vez de inventar una acción.

No se sintetizan herramientas de escritura en esta superficie MCP.
