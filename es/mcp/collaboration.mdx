Estas herramientas resuelven los identificadores que esperan las tools de escritura y leen el uso del workspace.

## Workspaces y uso

| Tool | Propósito | Devuelve |
| --- | --- | --- |
| `workspaces` | Listar los workspaces a los que tu credencial puede apuntar | slugs de workspace |
| `usage` | Leer el allowance comercial mensual (requests + créditos) | plan, límites, renovación |

Permisos: lecturas de nivel miembro. Disponibilidad: disponible. Cada tool acepta un argumento opcional `workspace` para apuntar a otro workspace autorizado para tu credencial.

```text
workspaces → [ { slug, name, role } ]
```

## Retirado del catálogo público

`members` (listar los miembros del workspace) y los comentarios (`context_comment`) no
tienen ninguna tool de MCP — sus definiciones y handlers fueron eliminados, no sólo
ocultos; una llamada legacy `driftless_*` ahora responde "Unknown tool". Ambos siguen
disponibles mediante el CLI y el dashboard — listar miembros no es trabajo de agente.
