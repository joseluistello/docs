Estas herramientas ayudan a un agente a elegir el workspace correcto y entender el uso actual antes de pedir más datos o hacer un cambio.

## Herramientas de workspace y uso

| Herramienta | Propósito |
| --- | --- |
| `workspaces` | Lista los workspaces a los que puede acceder la credencial. |
| `usage` | Lee el plan, límites, fecha de renovación y uso comercial actual. |

Ambas herramientas requieren acceso de miembro y aceptan un workspace sólo cuando la credencial está autorizada para él.

## Confirma antes de actuar

Pide al agente que muestre el nombre del workspace antes de una escritura, una búsqueda de contactos o una campaña. Una credencial de un workspace nunca debe usarse para leer otro.
