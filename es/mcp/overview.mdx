Brein expone las capacidades comerciales actuales de tu workspace mediante MCP. Un cliente de IA puede leer el contexto del equipo, buscar información de mercado, trabajar con contactos, preparar campañas e investigar.

Para configurar un cliente, empieza por [Conecta tu IA](/es/connect).

## Con qué puede trabajar el cliente

El catálogo público contiene **52 herramientas** en estas áreas:

| Área | Qué puede hacer el agente | Referencia |
| --- | --- | --- |
| Cerebro | Recuperar y actualizar la oferta, el perfil del comprador, las exclusiones, la geografía, los mensajes y las decisiones del equipo. | [Herramientas de Cerebro](/es/mcp/knowledge) |
| Prospectos | Leer contactos, actualizar un contacto y archivar una persona revelada o importada. | [Herramientas CRM](/es/mcp/work) |
| Mercado | Buscar proveedores, oportunidades, adjudicaciones, riesgos y permisos publicados. | [Herramientas de mercado](/es/mcp/overview#herramientas-de-mercado) |
| Campañas | Crear, previsualizar, aprobar, activar, pausar y medir secuencias. | [Herramientas de campañas](/es/mcp/sequences) |
| Investigador | Iniciar e inspeccionar investigación durable. | [Herramientas de research](/es/mcp/overview#herramientas-de-investigacion) |
| Workspace | Leer los workspaces y el uso comercial disponibles para la credencial. | [Herramientas de workspace](/es/mcp/collaboration) |
| Conexiones | Leer desde un provider que un administrador ya conectó. | [Herramientas de conexiones](/es/mcp/integrations) |

El cliente puede leer una lista amplia, pero cada llamada se verifica contra el workspace y el rol autorizados.

## Herramientas de mercado

Las herramientas de mercado responden preguntas acotadas sobre proveedores, oportunidades, adjudicaciones, riesgos y permisos publicados. Devuelven el resultado y el contexto de sus fuentes; no revelan coordenadas de contacto ni prometen un mercado completo.

## Herramientas de investigación

Las herramientas de investigación inician e inspeccionan corridas de Investigador. El resultado es un documento para revisar, no una conclusión automática. Las reglas, precios, permisos y detalles institucionales actuales pueden quedar como verificaciones explícitas.

## Autenticación

Usa OAuth cuando el cliente lo soporte:

1. Agrega el endpoint de Brein: `https://api.trybrein.com/mcp`
2. Abre el flujo de autorización del cliente.
3. Inicia sesión en Brein y selecciona el workspace.
4. Aprueba los permisos solicitados.

Una API key está disponible para integraciones soportadas y clientes self-hosted. Envíala mediante el almacén de secretos del cliente como `X-API-Key`; no pongas la key cruda en un repositorio.

Un `401` significa que la credencial falta o no es válida. Un `403` significa que la credencial es válida, pero no puede realizar la acción solicitada en ese workspace.

## Una primera solicitud segura

Empieza con una lectura sin efectos externos:

```text
Muestra los workspaces de Brein que puedo usar y el uso comercial actual.
```

Después prueba una búsqueda acotada o un fragmento del contexto del equipo antes de pedirle al agente que cambie un contacto o prepare una campaña. El agente debe mostrar la audiencia, el precio o la solicitud de aprobación antes de una acción que gaste créditos o envíe un mensaje.

## Comportamiento de las herramientas

- Las lecturas devuelven un resultado enfocado e indican cuando hay más páginas disponibles.
- Los datos de contacto permanecen ocultos hasta que la persona elige una búsqueda concreta.
- Las escrituras CRM se aplican al Record de contacto indicado en la solicitud.
- Un borrador de campaña no se envía solo; la activación requiere otra confirmación.
- Los clientes pueden cachear su lista de herramientas. Reconecta después de un cambio si falta una herramienta nueva.
