Estas son las **49 herramientas** públicas del MCP. La respuesta `tools/list` del servidor es el esquema canónico; si esta página y el esquema difieren, manda el esquema.

Todas aceptan `workspace` (opcional). **Sí** en la última columna quiere decir que una persona debe confirmar. **Créditos** quiere decir que puede gastarlos.

## Cerebro

| Herramienta | Qué hace | Sí |
|---|---|---|
| `context_read` | Busca (`query`), abre (`path`) o recorre las carpetas de Cerebro. | No |
| `context_write` | Crea un documento nuevo; rechaza una ruta que ya existe. | No |
| `context_propose_rewrite` | Paso 1: sella el texto nuevo completo contra la versión leída. | No |
| `context_rewrite` | Paso 2: escribe lo sellado. | Sí |

## Empresas, contactos y pipelines

| Herramienta | Qué hace | Sí |
|---|---|---|
| `crm_read` | Toda lectura de lo tuyo, por `object`: `company`, `contact`, `list`, `opportunity`, `product`. | No |
| `crm_collection` | Crea un pipeline con las etapas que se nombren. | No |
| `crm_propose_create` | Propone una oportunidad nueva y devuelve un `update_token`. | No |
| `crm_create_opportunity` | Crea la oportunidad aprobada. | Sí |
| `crm_propose_update` | Propone un cambio a una oportunidad. | No |
| `crm_update_opportunity` | Aplica el cambio aprobado. | Sí |
| `crm_propose_import` | Valida de 1 a 1000 filas sin escribir. | No |
| `crm_import_opportunities` | Aplica la importación aprobada. | Sí |
| `crm_schedule_activity` | Agenda un seguimiento. No manda ni mueve nada. | No |
| `crm_group_propose` | Paso 1 sobre un grupo: guardar en un pipeline, mover de etapa, archivar o desarchivar. Cuenta el grupo y no cambia nada. | No |
| `crm_group_apply` | Paso 2. Hasta 50 se aplica; más de 50 o un cambio de etapa piden `confirm`. | Según el caso |
| `contact_update` | Anota un hecho, corrige correo, teléfono o LinkedIn, o archiva. | No |
| `contact_file` | Guarda una persona ya revelada o importada en un pipeline. | No |

## Prospectar

| Herramienta | Qué hace | Sí |
|---|---|---|
| `prospect_companies` | Busca en el directorio de empresas, sin coordenadas. | No |
| `prospect_people` | Explora personas enmascaradas (directorio anterior). | No |
| `list_preview` | La muestra: 3 empresas con los mismos criterios, sin crear nada. | No |
| `list_save` | Arma, renombra, refresca o descarta una Lista. Gratis. | No |
| `list_quote` | Cotiza revelar las personas de una Lista. | No |

| `reveal` | Revela lo cubierto por una cotización aceptada. | Sí · créditos |

## Mercado y web

Solo leen. Devuelven resultados acotados con su fuente y nunca coordenadas de contacto.

| Herramienta | Qué hace | Sí |
|---|---|---|
| `market_resolve` | Ve qué hay para un nombre o tema: compradores, vendedores y empresas con conteos. | No |
| `market_aggregate` | Totales calculados en el servidor por hasta tres dimensiones. | No |
| `market_search_companies` | Busca en el directorio y en el padrón de importadores y exportadores. | No |
| `market_search_records` | Busca licitaciones, adjudicaciones, permisos y riesgos por `kind`. | No |
| `market_get` | Abre una fila por su `ref`. | No |
| `market_screen_risks` | Revisa hasta 50 RFC contra listas de riesgo. | No |
| `web_search` | Una foto del día de fuentes públicas. No guarda nada. | No |

Empieza con `market_resolve`, sigue con `market_aggregate` y lee filas solo cuando la pregunta ya es precisa. Un filtro adivinado devuelve cero filas sin significado: filtra por valores que una herramienta te mostró.

## Análisis y Reportes

| Herramienta | Qué hace | Sí |
|---|---|---|
| `analysis_save` | Responde una pregunta con 1 a 6 bloques que corre el servidor, más una lectura. | No |
| `analysis_read` | Lista los Análisis guardados o lee uno. | No |
| `report_preview` | Qué historias puede contar el espacio, o la muestra de un borrador, sin guardar. | No |
| `report_save` | Guarda un Reporte o agrega gráficas. Nunca quita ni cambia una. | No |
| `report_read` | Lista los Reportes o calcula uno ahora. | No |

| Herramienta | Qué hace | Sí |
|---|---|---|
| `form_read` | Lista formularios o abre uno con sus Respuestas, sin correo ni teléfono. | No |
| `form_save` | Crea o edita; publica solo cuando una persona lo pide. | Al publicar |

## Secuencias

Un borrador es inerte.

| Herramienta | Qué hace | Sí |
|---|---|---|
| `sequence_read` | Toda lectura por `view`: `list`, `detail`, `preview`, `metrics`, `analytics`, `mailboxes`. | No |
| `sequence_create_draft` | Crea un borrador. | No |
| `sequence_edit` | Edita el borrador y sus pasos. | No |
| `sequence_check` | Revisa si está lista y devuelve un token de activación. | No |
| `sequence_activate` | Empieza el envío real. | Sí · manda correo |
| `sequence_pause` | Detiene los próximos envíos. | No |
| `sequence_cancel` | Detiene para siempre a los pendientes. | No |
| `sequence_propose_reply` | Sella una respuesta escrita por una persona. | No |
| `sequence_reply_thread` | Manda la respuesta sellada. | Sí · manda correo |

## Cuenta

| Herramienta | Qué hace | Sí |
|---|---|---|
| `workspaces` | Los espacios que la credencial puede usar. | No |
| `usage` | El plan y los créditos. | No |

## Cómo usar el catálogo

1. Empieza con una lectura.
2. Confirma el espacio y la audiencia.
3. Corre la cotización, la vista previa o la revisión.
4. Llama la herramienta que escribe o activa solo después de que la persona confirme.
