---
title: 'How do I connect Brein to Codex or Cursor?'
description: 'Connect Brein to Codex or Cursor from their settings and use it while you work.'
---

If you work in Codex or Cursor, you can talk to Brein there too: ask for a customer list while you code, or check your pipeline without leaving your tool.

Brein connects with the same address in every client:

```text
https://api.trybrein.com/mcp
```

## Codex

It works the same in the Codex app and in its editor extension: both share the same configuration.

<Steps>
  <Step title="Open the MCP servers">
    In the Codex app: **Settings → MCP servers**. In the editor extension: the gear, then **MCP servers**.

    {/* CAPTURA: Codex, Settings → MCP servers */}
  </Step>
  <Step title="Add Brein">
    Tap **Add server**:

    - **Name:** `brein`
    - **Type:** Streamable HTTP
    - **URL:** `https://api.trybrein.com/mcp`

    Save and tap **Restart** (in the extension, **Restart extension**).
  </Step>
  <Step title="Sign in to Brein">
    In the list, Brein shows up as needing sign-in. Tap **Authenticate**: the browser opens, you sign in to Brein, pick your workspace and approve.

    {/* CAPTURA: Brein approval screen */}
  </Step>
  <Step title="Start a new conversation">
    Open a new conversation so Codex loads Brein's tools.
  </Step>
</Steps>

<Accordion title="Using Codex in the terminal?">
  Add Brein with `codex mcp add brein --url https://api.trybrein.com/mcp`, then sign in with `codex mcp login brein`. It is the same configuration the app and the extension use.
</Accordion>

## Cursor

<Steps>
  <Step title="Open the MCP settings">
    In Cursor's settings, find the **MCP** section and choose to add a new server. The menu name changes between versions; if you can't find it, search for «MCP» in the settings.

    {/* CAPTURA: Cursor, MCP settings */}
  </Step>
  <Step title="Paste the configuration">
    ```json
    {
      "mcpServers": {
        "brein": {
          "url": "https://api.trybrein.com/mcp"
        }
      }
    }
    ```
  </Step>
  <Step title="Connect">
    Brein shows up as needing sign-in. Tap **Connect**, sign in to Brein, pick your workspace and approve.
  </Step>
  <Step title="Check">
    Brein should show a green dot and its tools listed.
  </Step>
</Steps>

## Ask this to test it

> Show me the Brein workspaces I can use and how many credits I have left.

If it answers with your workspace and your plan, you are connected. Then: [your first requests](/work/first-requests).

  Using another tool, like VS Code, Windsurf, OpenCode or OpenClaw? See [how to connect another client](/connect/other-clients).
</Note>
