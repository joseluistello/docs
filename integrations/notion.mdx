description: 'Connect Notion as a bounded, read-only source with governed sync and external evidence.'

The Notion connector lets a workspace use selected Notion content as an external source without making Notion the customer-facing system of record. It is read-only from Brein's perspective: Brein does not write to Notion.

## Connect

Open **Configuración → Conexiones**, choose Notion, and complete the provider's authorization flow. The connection belongs to the current workspace. Credentials remain server-side in the provider vault and never appear in CLI output, MCP results, dashboard copy, logs, or citations.

## Read the connection

The CLI and REST Broker surface expose bounded operations:

```bash
driftless broker models notion
driftless broker records notion --model ContentMetadata --limit 5
driftless broker page <pageId>
```

- **Models** lists the read models available for the connection.
- **Records** reads bounded, delta-aware synced page metadata.
- **Page content** reads one page's bounded, citeable text live.

MCP does not expose a generic `driftless_broker` action router. When the provider is ready and the workspace rollout allows it, MCP may synthesize provider-specific read-only tools such as `notion_records` and `notion_document_content`. A synthesized tool is still subject to connection, rollout, grant, and workspace authorization.

## Materialize selected content

Reading a page and indexing it are different. To make selected Notion content available to connector-backed retrieval, preview the bounded import first:

```bash
driftless broker index notion --dry-run --model ContentMetadata --limit 10 --sample-limit 3
driftless broker index notion --model ContentMetadata --limit 10 --import-run-id notion-beta-1
```

Indexing writes only Brein-owned connector documents. It does not write to Notion, create a CRM Record, create a commercial truth document, or turn an external page into a contact.

Connector-backed retrieval is explicit. Results carry an external trust marker, citations, and freshness. Treat them as cited source material, not reviewed team knowledge.

## Safety and limits

- **Read-only:** no Notion writes are exposed.
- **Workspace-scoped:** a connection is visible only to the workspace that created it.
- **Bounded:** records and page content are paginated and size-capped; large pages return a clearly marked prefix.
- **Audited:** connection, sync, record, and page reads are recorded without logging page text.
- **External, not durable truth:** Notion content is never merged into Cerebro automatically.
