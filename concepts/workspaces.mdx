A workspace is the top-level container for Brein's commercial work, Cerebro, and connections. A person can belong to many workspaces and switch between them without creating a super credential.

## What belongs to a workspace

- Cerebro documents and their visibility;
- Prospectos Collections and contact Records;
- Companies, acquired Contacts, Lists, market evidence, Research, and Campaigns;
- members, roles, billing and commercial usage;
- integrations and scoped API credentials.

Every customer resource is workspace-scoped. A caller authorized for one workspace cannot use that credential to read another workspace's data.

## Identity and membership

Clerk authenticates the person. Membership in a workspace is a separate authorization fact stored in the workspace. A person is a non-member of a workspace unless a live membership row says otherwise; a non-member receives the same not-found behavior as an unavailable workspace resource.

| Role | Can |
|---|---|
| `owner` | Manage the workspace, members, roles, billing, credentials, and deletion. |
| `admin` | Manage ordinary workspace administration and members within owner boundaries. |
| `member` | Read and work the commercial surfaces and shared Cerebro documents within the workspace. |

The exact capability check lives in the API guard and the service that owns the action. A role never silently upgrades a credential across workspaces.

## Scoped credentials

An API key is issued for one or more authorized workspaces. `driftless login` registers the workspaces the key can reach, and `workspace switch` changes the local active target.

- Removing a person's membership revokes that person's live access.
- A key does not gain a higher role than its authorized human identity.
- OAuth MCP tokens can carry additional workspace grants after explicit consent.
- Key creation and revocation happen in the authenticated dashboard or through the workspace API.

## Workspaces in different surfaces

| Surface | Authentication | Active workspace |
|---|---|---|
| Dashboard | Clerk session | The workspace slug in the URL. |
| CLI | Scoped API key | The local workspace registry and active target. |
| MCP | API key or OAuth token | The token's authorized workspace or an explicitly supported target. |

The `driftless` namespace remains a compatibility contract for the CLI, package, API-key prefix, and hidden aliases. It is not a second product or a second workspace model.
