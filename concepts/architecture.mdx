## Components

### Scanner (`@driftless/scanner`)

Static AST analysis engine. Extracts components from TypeScript codebases:

- **NestJS**: endpoints, guards, services, modules, DTOs, interceptors, pipes
- **Next.js**: pages, layouts, route handlers, server actions, middleware
- **React**: components and hooks

The scanner uses a two-pass streaming pipeline — facts are processed as they're extracted without accumulating all file results in memory. Peak memory is O(largest file). Zero runtime dependencies beyond TypeScript.

### API (NestJS, Render)

REST API at `api.driftless.icu`. Built on NestJS with TypeORM and Supabase (Postgres).

- **45 endpoints** across workspaces, context, scan, graph, and webhooks
- **Auth** via API keys (`x-api-key` header) for CLI and Clerk for dashboard sessions
- **Global WorkspaceGuard** enforces multi-tenant isolation — every request is scoped to a workspace
- **No caching** by design — direct database queries only (see [ADR: No caching layer](/decisions/no-cache))

### Dashboard (React + Vite, Vercel)

Web UI at `driftless.icu`. Provides:

- Workspace health overview and module-level architecture maps (ReactFlow + dagre)
- Context browser and topic graph explorer
- PR activity log with sticky context comments
- Settings: API keys, tracked branches, integrations

### CLI (`@driftless-sh/cli`, npm)

24 commands bundled with esbuild into a single binary. Core workflows:

- `init`, `scan`, `sync` — baseline and drift detection
- `context add|get|update|list|search|load|link|doctor|graph` — full context CRUD
- `graph file|impact` — blast radius analysis
- `branches add|remove|list` — tracked branch management
- `install-skill` — install the agent skill into consumer repos

### GitHub App

Installed on repos. Two main functions:

- **PR observation**: Posts context comments listing topics relevant to changed files
- **Push staleness**: Matches changed files on tracked branches against anchored topics, marks matches as stale

The app never blocks merges or modifies code.

### Agent Skill (`SKILL.md`)

A markdown file that teaches coding agents (Claude Code, Cursor) the Driftless workflow. Installed by `driftless install-skill` or `driftless init`. The skill instructs agents to:

1. Sync before starting a session
2. Load context for files they're about to touch
3. Persist discoveries back to Cloud

The canonical source of the skill lives in the Driftless monorepo. A mirror repo (`github.com/driftless-sh/driftless-skill`) serves it for installation via raw URL.
