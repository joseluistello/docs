Base URL:

```text
https://api.trybrein.com/api/v1
```

## Authentication

Workspace resources require an authenticated API key, a Clerk session, or an authorized OAuth token. A missing or invalid credential returns `401`; an authenticated caller without the required workspace scope returns `403`.

```bash
curl https://api.trybrein.com/api/v1/me \
  -H "x-api-key: drift_your_api_key_here"
```

Treat API keys as secrets. Brein stores them encrypted and shows the raw value only when it is created.

## Workspace resources

| Resource | Main routes | Customer job |
|---|---|---|
| Workspace and team | `/workspaces/:slug`, `/members`, `/api-keys` | Manage the workspace, people, roles, and scoped credentials. |
| Commercial usage | `/workspaces/:slug/commercial-usage` | Read plan, requests, intelligence credits, contact credits, renewal, and upgrade action. |
| Cerebro documents | `/workspaces/:slug/documents/*` | Read and write markdown documents in folders. |
| CRM | `/workspaces/:slug/collections/*` | Operate contact Records and their bounded lifecycle. |
| Companies and people | `/workspaces/:slug/radar/*` | Search companies, discover masked people, reveal selected people, manage acquired contacts, and file them. |
| Lists | `/workspaces/:slug/radar/lists/*` | Save, refresh, quote, reveal, and export a selected people-search result. |
| Market Data | `/workspaces/:slug/market-data/*` | Run typed, read-only supplier, opportunity, award, risk, and permit operations. |
| Explorer | `/workspaces/:slug/intelligence/explorer/*` | Search and inspect the customer-facing company/evidence explorer. |
| Research | `/workspaces/:slug/research/*` | Start, inspect, stream, and cancel durable Investigador runs. |
| Email and campaigns | `/workspaces/:slug/email-campaigns/*`, `/email-mailboxes/*` | Prepare, review, authorize, activate, pause, and measure outbound sequences. |
| Integrations | `/workspaces/:slug/integrations/*` | List, connect, confirm, reconnect, and disconnect providers. |
| Broker | `/workspaces/:slug/broker/*` | Inspect and run governed operations over an existing connection. |

Every workspace route is workspace-scoped and authenticated. A caller cannot use one workspace's key or route to read another workspace's data.

## Public infrastructure routes

The public surface is intentionally small. It includes runtime health and version routes, the first-run workspace bootstrap, public website content routes, OAuth discovery/register/token endpoints, signed webhook receivers, unsubscribe/share endpoints, and other explicitly public platform routes.

The exact public allowlist is owned by the API and its route decorators; do not infer that a resource is public because a client does not currently show a session. See [Errors](/api/errors) for the common envelope and [Security](/security/overview) for data boundaries.

## Market and activation boundary

Market analysis is separate from contact activation:

- market reads, counts, comparisons, history, and aggregates do not spend credits;
- a company detail that actually returns a published coordinate can spend an intelligence credit;
- contact reveal is person-first, quoted for the selected group, separately confirmed, and charged against the separate contact balance;
- a failed or empty reveal is refunded and never triggers an automatic provider fallback.

Successful commercial responses expose the current usage state. An exhausted allowance fails closed with an actionable `402`; it does not turn into a generic cancellation.

## Compatibility surfaces

The API keeps some Topics, sharing, relation, and legacy CLI compatibility routes mounted. They are not the primary customer model. The current Cerebro model is documents in folders; the current CRM model is contact-first Records; and the current MCP catalog uses neutral capability names. Historical rows and routes may remain until their active consumers migrate, but compatibility is not a new product surface.
