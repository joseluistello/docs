Base URL:

```text
https://api.trybrein.com/api/v1
```

Use the REST API when your software needs to read or change a Brein workspace directly. For an AI client, start with [MCP and OAuth](/mcp/overview) instead.

## Authentication

Send a scoped API key in the `x-api-key` header:

```bash
curl https://api.trybrein.com/api/v1/me \
  -H "x-api-key: <your-api-key>"
```

A missing or invalid key returns `401`. A valid key without permission for the workspace or action returns `403`.

Keep keys in your secret manager. Never commit them to source control or put them in customer-facing output.

## Main resources

| Resource | Base path | Use it for |
| --- | --- | --- |
| Workspace and usage | `/workspaces/:slug` | Read workspace details, team access, and commercial usage. |
| Cerebro | `/workspaces/:slug/documents/*` | Read and update documents in folders. |
| Prospectos | `/workspaces/:slug/collections/*` | Read and update contact records. |
| Companies and people | `/workspaces/:slug/radar/*` | Search companies, review masked people, and work with acquired contacts. |
| Market information | `/workspaces/:slug/market-data/*` | Run read-only supplier, opportunity, award, risk, and permit operations. |
| Research | `/workspaces/:slug/research/*` | Start, inspect, and cancel Investigador runs. |
| Campaigns | `/workspaces/:slug/email-campaigns/*` | Prepare, review, activate, pause, and measure email sequences. |
| Connections | `/workspaces/:slug/integrations/*` | List and manage approved provider connections. |

Every workspace route is scoped to the workspace in the URL. Do not assume that a route from one workspace can be used with another workspace's credentials.

## Usage and actions

Reads and contact actions have different cost rules. A successful response can include the current usage state. If an allowance is exhausted, the API returns an actionable `402` instead of silently continuing.

Contact lookup is separate from saving a contact. Campaign creation is separate from campaign activation. A campaign is not sent until the required human confirmation succeeds.
