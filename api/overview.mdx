The Driftless API is a RESTful JSON API.

**Base URL:** `https://api.driftless.icu/api/v1`

## Conventions

All request and response bodies are JSON. Every response includes `Content-Type: application/json`.

### Standard Error Response

```json
{
  "statusCode": 404,
  "message": "Workspace not found",
  "request_id": "req_abc123",
  "retryable": false,
  "endpoint": "GET /api/v1/workspaces/my-workspace"
}
```

| Field | Description |
| --- | --- |
| `statusCode` | HTTP status code |
| `message` | Human-readable description |
| `request_id` | Correlation ID for tracing |
| `retryable` | `true` for 5xx errors, `false` for 4xx |
| `endpoint` | The method and path that was called |

### Pagination

Endpoints that return lists support cursor or offset pagination:

```
?limit=50&offset=0
```

- `limit` — Max items per page (varies by endpoint, typically 50)
- `offset` — Number of items to skip

### Rate Limiting

| Tier | Limit | Scope |
| --- | --- | --- |
| Webhook | 100 req/min | Per IP |
| Public | 30 req/min | Per IP |
| Authenticated | 200 req/min | Per API key or token |

Rate limit headers are included on every response:
- `X-RateLimit-Limit`
- `X-RateLimit-Remaining`
- `X-RateLimit-Reset`

### Correlation

Send an `x-correlation-id` header with your requests to trace them through logs. If omitted, one is auto-generated and returned in the response.

```bash
curl -H "X-API-Key: drift_xxx" \
     -H "x-correlation-id: my-trace-001" \
     https://api.driftless.icu/api/v1/me
```

## Health Check

```bash
curl https://api.driftless.icu/health
# or
curl https://api.driftless.icu/api/v1/health
```

```json
{
  "status": "ok",
  "uptime": 123456,
  "timestamp": "2025-01-01T00:00:00.000Z"
}
```

## Version

```bash
curl https://api.driftless.icu/api/v1/version
```

```json
{
  "version": "0.1.0",
  "commit": "abc1234",
  "branch": "main",
  "nodeVersion": "20.11.0"
}
```
