## All Endpoints

Base URL: `https://api.driftless.icu/api/v1` unless noted.

### Health & Version

| Method | Path | Auth | Description |
|--------|------|------|-------------|
| `GET` | `/health` | Public | Render health check |
| `GET` | `/version` | Public | Version info |

| `GET` | `/api/v1/version` | Public | Version info (API prefix) |

<AccordionGroup>
  <Accordion title="Auth Legend">
    - **Public**: No authentication required. Rate limit: 30 req/min.
    - **Auth**: Requires `X-API-Key` header (CLI) or `Authorization: Bearer <token>` (dashboard). Rate limit: 200 req/min.
    - **Webhook**: Requires HMAC signature verification. Rate limit: 50-100 req/min.
  </Accordion>
  <Accordion title="Error Response Format">
    ```json
    {
      "statusCode": 404,
      "message": "Repo not found",
      "request_id": "f9b8d7a1-...",
      "retryable": false,
      "endpoint": "GET /api/v1/workspaces/my-org/repos/123"
    }
    ```
    - `retryable`: `true` for 5xx, `false` for 4xx
    - `request_id`: Correlation ID for tracing
  </Accordion>
</AccordionGroup>
