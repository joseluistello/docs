Driftless accepts webhooks from GitHub and Clerk to drive stale detection, PR context comments, and organization invitations.

## GitHub Webhook

```
POST /webhooks/github
```

- **Auth:** None (public endpoint)
- **Rate limit:** 100 req/min
- **Signature:** HMAC-SHA256 via `x-hub-signature-256` header

<Note>
  This endpoint requires raw body parsing. In NestJS, configure it with:
  ```ts
  app.use('/webhooks/github', express.raw({ type: 'application/json' }))
  ```
</Note>

### Events Handled

#### `push`

Matches changed files against all workspace topics on tracked branches and marks matching topics stale.

**Staleness processing:**
- Matches each changed file against `where_files`, `patterns`, and component assocations
- Sets matching topics as stale with reason (commit hash, changed files list)
- Records `WebhookEvent`, `WatcherEvent`, and `ContextEvent` records
- **Structural staleness:** detects deleted files and removed endpoints, guards, or services

#### `pull_request`

Triggers on: `opened`, `synchronize`, `reopened`, `ready_for_review`

1. Fetches PR files via GitHub App installation token
2. Matches changed files against workspace topics
3. Posts or updates a context comment on the PR listing relevant topics
4. Records a `PRObservation`

#### `ping`

Verifies the webhook is correctly configured. Returns `{ event: "pong" }`.

#### `installation` / `installation_repositories`

Links the GitHub App installation to the workspace:

- **`deleted`** — Deactivates the integration
- **`created`** — Auto-links by matching org name or existing repos
- Falls back to a `PendingInstallation` if no match is found

## Clerk Webhook

```
POST /webhooks/clerk
```

- **Auth:** None (public endpoint)
- **Rate limit:** 50 req/min
- **Signature:** Verified via Svix headers (`svix-id`, `svix-timestamp`, `svix-signature`)

<Note>
  This endpoint requires raw body parsing. In NestJS, configure it with:
  ```ts
  app.use('/webhooks/clerk', express.raw({ type: 'application/json' }))
  ```
</Note>

### Event Handled

#### `organizationInvitation.created`

1. Fetches organization details from Clerk API
2. Fetches inviter profile
3. Retrieves the invitation
4. Sends an HTML invitation email via [Resend](https://resend.com)

## Integrations API

### List Integrations

```bash
curl -H "X-API-Key: drift_xxx" \
     https://api.driftless.icu/api/v1/workspaces/my-team/integrations
```

Returns `Integration[]`.

### Create Integration

```bash
curl -X POST https://api.driftless.icu/api/v1/workspaces/my-team/integrations \
  -H "X-API-Key: drift_xxx" \
  -H "Content-Type: application/json" \
  -d '{ "type": "github", "config": { "installation_id": "12345" } }'
```

### Delete Integration

```bash
curl -X DELETE \
     -H "X-API-Key: drift_xxx" \
     https://api.driftless.icu/api/v1/workspaces/my-team/integrations/integration_uuid
```

```json
{ "status": "deleted" }
```

## PR Activity

Retrieve PR observations recorded during webhook processing:

```bash
curl -H "X-API-Key: drift_xxx" \
     "https://api.driftless.icu/api/v1/workspaces/my-team/pr-activity?limit=50&offset=0&status=open&repo_id=repo_uuid&branch=main"
```

<ParamField query="query" type="object">
  <ParamField name="limit" type="number" optional defaultValue="50">
    Max observations per page.
  </ParamField>
  <ParamField name="offset" type="number" optional defaultValue="0">
    Pagination offset.
  </ParamField>
  <ParamField name="status" type="string" optional>
    Filter by PR status (`open`, `closed`, `merged`).
  </ParamField>
  <ParamField name="repo_id" type="string" optional>
    Filter by repository ID.
  </ParamField>
  <ParamField name="branch" type="string" optional>
    Filter by branch name.
  </ParamField>
</ParamField>

```json
{
  "observations": [ ... ],
  "total": 42,
  "branches": ["main", "develop", "feat/auth"]
}
```
