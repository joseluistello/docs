## Integrations

| Method | Path | Purpose |
|---|---|---|
| `GET` | `/workspaces/:slug/integrations` | List integrations |
| `POST` | `/workspaces/:slug/integrations` | Create or connect an integration |
| `DELETE` | `/workspaces/:slug/integrations/:id` | Remove an integration |
