Topics (also called watchers) are the core context unit in Driftless. Each topic captures *what* something is, *how* it works, and *where* it lives.

## List & Search

### List Topics

```bash
curl -H "X-API-Key: drift_xxx" \
     "https://api.driftless.icu/api/v1/workspaces/my-team/watchers?stale=true&kind=code-context&repo=repo_uuid"
```

Query parameters:

| Param | Type | Description |
| --- | --- | --- |
| `stale` | boolean | Filter stale topics |
| `docs` | boolean | Filter topics with anchored docs |
| `auto` | boolean | Filter auto-generated topics |
| `manual` | boolean | Filter manually created topics |
| `suggested` | boolean | Filter suggested topics |
| `status` | string | Filter by status |
| `kind` | string | Filter by kind (e.g. `code-context`, `decision`) |
| `repo` | UUID | Filter by repository ID |

Returns `CanonicalContextSummary[]`.

### Full-Text Search

```bash
curl -H "X-API-Key: drift_xxx" \
     "https://api.driftless.icu/api/v1/workspaces/my-team/watchers/search?q=auth middleware"
```

Uses Postgres `to_tsvector` + `ILIKE` for combined full-text and pattern matching.

### Audit

```bash
curl -H "X-API-Key: drift_xxx" \
     https://api.driftless.icu/api/v1/workspaces/my-team/watchers/audit
```

```json
{
  "total": 42,
  "stale": [{ "slug": "auth-guard", "reason": "File changed in commit abc123" }],
  "orphaned": 3,
  "draft": 5,
  "docs_pending": 2,
  "repo_leak": 1
}
```

### Match Files to Topics

```bash
curl -X POST https://api.driftless.icu/api/v1/workspaces/my-team/watchers/match-files \
  -H "X-API-Key: drift_xxx" \
  -H "Content-Type: application/json" \
  -d '{ "files": ["src/auth/guard.ts", "src/users/service.ts"] }'
```

Returns topics matching the given files, including match reason.

## CRUD

### Create Topic

```bash
curl -X POST https://api.driftless.icu/api/v1/workspaces/my-team/watchers \
  -H "X-API-Key: drift_xxx" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Auth Guard",
    "what": "Global authentication guard for all routes",
    "how": "Applied as APP_GUARD, checks JWT tokens via Clerk",
    "patterns": ["src/auth/*.ts"],
    "decisions": ["Use Clerk over custom JWT for session management"],
    "gotchas": ["Must exempt health endpoint with @Public()"],
    "tags": ["auth", "middleware"],
    "kind": "code-context"
  }'
```

  </ParamField>

  </ParamField>

Wiki-links in the `content` field (e.g. `[[auth-guard]]`) are automatically parsed and create topic references.

### Update Topic

```bash
curl -X PATCH https://api.driftless.icu/api/v1/workspaces/my-team/watchers/auth-guard \
  -H "X-API-Key: drift_xxx" \
  -H "Content-Type: application/json" \
  -d '{
    "what": "Updated description",
    "_append_gotchas": ["New edge case found with WebSocket"],
    "_add_patterns": ["src/websocket/**"],
    "expected_version": 3
  }'
```

**Optimistic concurrency:** Pass `expected_version` to ensure you're updating the latest version. On mismatch, returns a `409 Conflict`.

**Atomic appends** (idempotent — duplicates are ignored):
- `_append_gotchas` — Append to gotchas array
- `_append_decisions` — Append to decisions array
- `_append_invariants` — Append to invariants array
- `_append_required_checks` — Append to required checks

**Idempotent anchors:**
- `_add_patterns` — Add file patterns
- `_remove_patterns` — Remove file patterns

**Cross-repo linking:**
- `_add_repo` — Link this topic to a repository in another workspace

### Delete Topic

```bash
curl -X DELETE \
     -H "X-API-Key: drift_xxx" \
     https://api.driftless.icu/api/v1/workspaces/my-team/watchers/auth-guard
```

```json
{ "status": "deleted" }
```

Cascades: associated events are also deleted.

## Relations

### Create Relation

```bash
curl -X POST https://api.driftless.icu/api/v1/workspaces/my-team/watchers/auth-guard/relations \
  -H "X-API-Key: drift_xxx" \
  -H "Content-Type: application/json" \
  -d '{ "to_slug": "b2b-routing", "relation_type": "depends_on" }'
```

**Relation types:** `relates_to`, `depends_on`, `supersedes`, `blocks`, `implements`, `documents`, `risk_for`.

### List Relations

```bash
curl -H "X-API-Key: drift_xxx" \
     https://api.driftless.icu/api/v1/workspaces/my-team/watchers/auth-guard/relations
```

```json
{
  "outgoing": [{ "id": "uuid", "to_slug": "b2b-routing", "relation_type": "depends_on" }],
  "incoming": [{ "id": "uuid", "from_slug": "api-keys", "relation_type": "relates_to" }]
}
```

### Delete Relation

```bash
curl -X DELETE \
     -H "X-API-Key: drift_xxx" \
     https://api.driftless.icu/api/v1/workspaces/my-team/watchers/auth-guard/relations/relation_uuid
```

```json
{ "status": "deleted" }
```
