## Repos CRUD

### Register a Repo

```bash
curl -X POST https://api.driftless.icu/api/v1/workspaces/my-team/repos \
  -H "X-API-Key: drift_xxx" \
  -H "Content-Type: application/json" \
  -d '{
    "github_org": "my-org",
    "github_repo": "my-repo",
    "github_webhook_secret": "optional-secret"
  }'
```

<ParamField query="body" type="object">
  <ParamField name="github_org" type="string" required>
    GitHub organization or user name. Validated via regex.
  </ParamField>
  <ParamField name="github_repo" type="string" required>
    GitHub repository name. Validated via regex.
  </ParamField>
  <ParamField name="github_webhook_secret" type="string" optional>
    Custom webhook secret. If omitted, one is auto-generated.
  </ParamField>
</ParamField>

### List Repos

```bash
curl -H "X-API-Key: drift_xxx" \
     https://api.driftless.icu/api/v1/workspaces/my-team/repos
```

Returns `Repo[]`.

### Get Repo Detail

```bash
curl -H "X-API-Key: drift_xxx" \
     https://api.driftless.icu/api/v1/workspaces/my-team/repos/repo_uuid
```

```json
{
  "repo": { "id": "...", "github_org": "my-org", "github_repo": "my-repo" },
  "components": [ ... ],
  "relations": [ ... ]
}
```

### Update Tracked Branches

```bash
curl -X PATCH https://api.driftless.icu/api/v1/workspaces/my-team/repos/repo_uuid \
  -H "X-API-Key: drift_xxx" \
  -H "Content-Type: application/json" \
  -d '{ "tracked_branches": ["main", "develop"] }'
```

Constraints:
- Max 20 branches
- Each branch name < 255 characters
- Alphanumeric plus `.`, `_`, `-`, `/`

### Delete a Repo

```bash
curl -X DELETE \
     -H "X-API-Key: drift_xxx" \
     https://api.driftless.icu/api/v1/workspaces/my-team/repos/repo_uuid
```

Full cleanup: unlinks the repo from all topics and orphans topics with no remaining repos.

```json
{
  "status": "deleted",
  "deleted": true,
  "topicsUnlinked": 5,
  "orphanedTopics": ["slug-1", "slug-2"]
}
```

## Components

### Upload Components

Upload scanned components in chunks. Runs inside a database transaction.

```bash
curl -X POST https://api.driftless.icu/api/v1/workspaces/my-team/repos/repo_uuid/components \
  -H "X-API-Key: drift_xxx" \
  -H "Content-Type: application/json" \
  -d '{
    "schema_version": 1,
    "replace": true,
    "components": [
      {
        "type": "controller",
        "name": "UserController",
        "file_path": "src/users/user.controller.ts",
        "line_number": 12,
        "metadata": { "methods": ["GET", "POST"] },
        "relations": [
          {
            "type": "calls",
            "target_name": "UserService",
            "target_file": "src/users/user.service.ts"
          }
        ]
      }
    ]
  }'
```

<ParamField query="body" type="object">
  <ParamField name="schema_version" type="number" optional>
    Schema version for forward compatibility.
  </ParamField>
  <ParamField name="replace" type="boolean" optional defaultValue="true">
    Whether to replace all existing components for this repo.
  </ParamField>
  <ParamField name="components" type="array" required>
    Array of component objects.
  </ParamField>
</ParamField>

```json
{ "status": "stored", "count": 42 }
```

### Get Component Detail

```bash
curl -H "X-API-Key: drift_xxx" \
     https://api.driftless.icu/api/v1/workspaces/my-team/repos/repo_uuid/components/UserController
```

```json
{
  "component": { "name": "UserController", "type": "controller", "file_path": "..." },
  "outgoing": [ ... ],
  "incoming": [ ... ]
}
```

## Scan

### Upload Baseline

Store a baseline snapshot (used for diff comparisons):

```bash
curl -X POST https://api.driftless.icu/api/v1/workspaces/my-team/repos/repo_uuid/baseline \
  -H "X-API-Key: drift_xxx" \
  -H "Content-Type: application/json" \
  -d '{ "key": "value" }'
```

```json
{ "status": "stored" }
```

Sets the repo status to `ready`.

### Trigger Full Scan

Clones the repo via git, runs the scanner, persists components, creates auto-watchers, and records context events:

```bash
curl -X POST https://api.driftless.icu/api/v1/workspaces/my-team/repos/repo_uuid/scan \
  -H "X-API-Key: drift_xxx"
```

```json
{
  "status": "ready",
  "summary": {
    "components": 142,
    "modules": 12,
    "watchers_created": 8,
    "scan_duration_ms": 2340
  }
}
```

On failure:

```json
{ "status": "error", "error": "Clone failed: repository not found" }
```

## Architecture Summary

Get a module-level architecture overview:

```bash
curl -H "X-API-Key: drift_xxx" \
     https://api.driftless.icu/api/v1/workspaces/my-team/repos/repo_uuid/architecture-summary
```

```json
{
  "repo": { "id": "...", "name": "my-repo" },
  "modules": [
    { "name": "users", "components": 8, "types": { "controller": 1, "service": 1, "module": 1, "dto": 2 } }
  ],
  "module_relations": [
    { "from": "users", "to": "auth", "type": "imports" }
  ],
  "components_by_module": {
    "users": 8,
    "auth": 5
  },
  "total_components": 142,
  "total_relations": 234,
  "coverage": { "covered": 8, "total": 12, "percentage": 66.7 }
}
```
