## Workspaces

A workspace is the top-level container for repos, topics, and team context.

### Create Workspace

<ParamField query="body" type="object" defaultValue={null}>
  <ParamField name="name" type="string" required>
    Display name for the workspace.
  </ParamField>
  <ParamField name="slug" type="string" required>
    URL-friendly identifier. Example: `my-team`.
  </ParamField>
</ParamField>

```bash
curl -X POST https://api.driftless.icu/api/v1/workspaces \
  -H "Content-Type: application/json" \
  -d '{ "name": "My Team", "slug": "my-team" }'
```

### Get Workspace

```bash
curl -H "X-API-Key: drift_xxx" \
     https://api.driftless.icu/api/v1/workspaces/my-team
```

### Update Workspace

```bash
curl -X PATCH https://api.driftless.icu/api/v1/workspaces/my-team \
  -H "X-API-Key: drift_xxx" \
  -H "Content-Type: application/json" \
  -d '{ "name": "New Name" }'
```

### Get Authenticated User's Workspace

```bash
curl -H "X-API-Key: drift_xxx" \
     https://api.driftless.icu/api/v1/me
```

```json
{
  "workspace_id": "uuid",
  "name": "My Team",
  "slug": "my-team"
}
```

## Members

### List Members

```bash
curl -H "X-API-Key: drift_xxx" \
     https://api.driftless.icu/api/v1/workspaces/my-team/members
```

Returns `WorkspaceMember[]`.

### Add Member

<ParamField query="body" type="object" defaultValue={null}>
  <ParamField name="clerk_user_id" type="string" required>
    The Clerk user ID to add.
  </ParamField>
  <ParamField name="role" type="string" optional>
    Defaults to `"member"`. Options: `"member"`, `"admin"`.
  </ParamField>
</ParamField>

```bash
curl -X POST https://api.driftless.icu/api/v1/workspaces/my-team/members \
  -H "X-API-Key: drift_xxx" \
  -H "Content-Type: application/json" \
  -d '{ "clerk_user_id": "user_xxx", "role": "admin" }'
```

This endpoint is idempotent — adding an existing member returns the existing record.

### Remove Member

```bash
curl -X DELETE \
     -H "X-API-Key: drift_xxx" \
     https://api.driftless.icu/api/v1/workspaces/my-team/members/member_uuid
```

```json
{ "status": "removed" }
```

## Health Snapshot

Get a health overview of a workspace:

```bash
curl -H "X-API-Key: drift_xxx" \
     https://api.driftless.icu/api/v1/workspaces/my-team/health
```

<Accordion title="Response Shape">
  <ResponseField name="health_score" type="number">
    Composite health score (0–100).
  </ResponseField>
  <ResponseField name="grade" type="string">
    Letter grade: A (90+), B (75+), C (60+), D (40+), F (&lt;40).
  </ResponseField>
  <ResponseField name="repos" type="object">
    <ResponseField name="total" type="number" />
    <ResponseField name="ready" type="number" />
    <ResponseField name="scanning" type="number" />
    <ResponseField name="error" type="number" />
    <ResponseField name="pending" type="number" />
  </ResponseField>
  <ResponseField name="components" type="object">
    <ResponseField name="total" type="number" />
    <ResponseField name="by_type" type="object">
      Breakdown by component type (module, controller, service, etc.).
    </ResponseField>
  </ResponseField>
  <ResponseField name="watchers" type="object">
    <ResponseField name="total" type="number" />
    <ResponseField name="stale" type="number" />
    <ResponseField name="with_doc" type="number" />
    <ResponseField name="auto" type="number" />
    <ResponseField name="manual" type="number" />
  </ResponseField>
  <ResponseField name="coverage" type="object">
    <ResponseField name="covered" type="number" />
    <ResponseField name="total" type="number" />
    <ResponseField name="percentage" type="number" />
  </ResponseField>
  <ResponseField name="scans" type="object">
    <ResponseField name="last_scan_at" type="string | null">
      ISO timestamp of the most recent scan.
    </ResponseField>
    <ResponseField name="scans_7d" type="number" />
    <ResponseField name="stale_repos" type="number" />
  </ResponseField>
  <ResponseField name="activity_7d" type="number">
    Total events in the last 7 days.
  </ResponseField>
  <ResponseField name="breakdown" type="object">
    <ResponseField name="coverage_pts" type="number">
      Points from coverage percentage (55% weight).
    </ResponseField>
    <ResponseField name="freshness_pts" type="number">
      Points from scan freshness (25% weight).
    </ResponseField>
    <ResponseField name="stale_pts" type="number">
      Points from stale topic ratio (20% weight).
    </ResponseField>
  </ResponseField>
</Accordion>

### Scoring Formula

The health score is a weighted sum:

- **55%** — Coverage: `(covered / total) * 55`
- **25%** — Freshness: recency and frequency of scans
- **20%** — Stale ratio: `(1 - stale/total) * 20`
