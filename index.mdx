## The agent loop in 3 commands

<Steps>
  <Step>
    **Sync** — See what the team changed since your last session.

    ```bash
    driftless sync
    ```
  </Step>
  <Step>
    **Load** — Get context for the files you're about to touch.

    ```bash
    driftless context load --files "src/auth/guard.ts,src/users/service.ts"
    ```
  </Step>
  <Step>
    **Persist** — Write what you learned back to the team.

    ```bash
    driftless context update auth --gotcha "JWT decode happens in guard, not middleware"
    ```
  </Step>
</Steps>

## What Driftless is NOT

- **Not a PR reviewer** — It observes PRs and posts context comments, but doesn't approve or reject.
- **Not CI** — It doesn't run tests, block merges, or gate deploys.
- **Not a cache** — No Redis, no in-memory cache. Direct database queries only.
- **Not an MCP server** — The CLI and REST API are the only interfaces. No MCP in v1.
