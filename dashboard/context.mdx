The Context panel is your living catalog of every topic Driftless knows about. Browse, filter, search, inspect, and create topics — all from one view.

## KPI Header

The top bar shows aggregate counts:

| Metric | Description |
|---|---|
| **Total** | All topics in the workspace |
| **Reviewed** | Topics marked reviewed |
| **Draft** | Topics pending review |
| **Stale** | Topics flagged as drifted |
| **With docs** | Topics that include linked documentation |

## Filters

Narrow the topic list with compound filters:

| Filter | Options |
|---|---|
| **Status** | `reviewed`, `draft`, `orphaned`, `suggested` |
| **Repo** | Any connected repository |
| **Kind / Type** | `code-context`, `decision`, `docs-pending`, `domain-map` |
| **Origin / Source** | `auto` (scanner-generated), `manual` (team-written), `doc` (anchored document), `agent` (agent-contributed) |
| **Search** | Free-text search across topic name, content, and tags |

Filters stack. Selecting **auto** and **stale** shows scanner-generated topics needing review.

## Topic Cards

Each topic in the list shows:

- **Name** and **badges** (`draft`, `stale`, `auto`, `doc`)
- **Pattern** — the file glob anchoring the topic
- **Summary** — the "what" field
- **Stale reason** — why the topic was flagged (if applicable)
- **File count** — number of files matched by the pattern

## New Topic Form

Inline creation at the top of the list. Provide:

- **Name** (slug)
- **What** (summary)
- **Patterns** (file globs)
- **Kind** (code-context, decision, etc.)
- **Status** (reviewed, draft)

## Orphaned Topic Banner

A yellow banner appears when orphaned topics exist — topics whose patterns no longer match any files in the repo. Click the banner to filter to orphaned topics and clean them up.

## Pagination

Offset and limit controls at the bottom of the list. Default page size is 20 topics.

## Detail Panel

Click any topic card to open its full detail view at `/context/:slug`. The detail panel shows what, how, decisions, gotchas, invariants, patterns, relations, history timeline, and the CLI fetch command for agents.
