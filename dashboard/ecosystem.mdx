The Ecosystem page is the control room for your workspace. It shows health metrics, connected repos, and a setup checklist that walks new workspaces through getting fully operational.

## Health Score

Your workspace receives an overall **Health Score** (A-F) calculated from:

| Weight | Factor |
|---|---|
| **55%** | Context coverage — percentage of modules with at least one topic |
| **25%** | Scan freshness — how recently repos were scanned |
| **20%** | Stale ratio — percentage of topics flagged as drifted |

### KPI Cards

The top of the page displays key metrics at a glance:

| KPI | Description |
|---|---|
| **Total repos** | Repositories connected to your workspace |
| **Total components** | All scanned components across all repos |
| **Total topics** | All context topics in the workspace |
| **Stale topics** | Topics flagged as drifted |
| **Coverage %** | Modules covered by at least one topic |
| **Last scan** | Most recent scan date across repos |

## Repo List

Each connected repo shows:

| Field | Description |
|---|---|
| **Status** | `ready`, `scanning`, `error`, or `pending` |
| **Components** | Number of components extracted by the scanner |
| **Last scan** | Date of the most recent scan |

Actions available per repo: **Scan** (re-trigger scanner) and **Delete** (removes repo, components, and topic associations). A registration form at the bottom lets you add new repos.

## PR Sparkline

A 7-day mini-chart of PR observation activity, rendered as an SVG sparkline. Shows how many PRs were observed each day.

## Setup Checklist

For new workspaces, a guided checklist appears until all steps are complete:

<Steps>
  <Step title="Install GitHub App">
    Connect Driftless to your GitHub organization. See [GitHub App Integration](/integrations/github-app).
  </Step>
  <Step title="Run smart init">
    ```bash
    driftless init
    ```
    Uploads structural baseline and generates initial topic suggestions.
  </Step>
  <Step title="Create first topic">
    ```bash
    driftless context add "my-first-topic" --what "Description" --pattern "src/path/**"
    ```
  </Step>
  <Step title="Install agent skill">
    ```bash
    driftless install-skill
    ```
    Teaches coding agents to load context before editing.
  </Step>
</Steps>

## Context Integrity KPIs

The lower panel shows integrity metrics for your topics:

| Metric | Description |
|---|---|
| **Total** | All topics in the workspace |
| **Stale** | Drifted topics needing review |
| **Orphaned** | Topics with no matching components |
| **Draft** | Topics pending review |
| **Docs-pending** | Topics flagged as needing documentation |

## Welcome Flow

First-time workspaces see a guided onboarding flow that walks through the setup checklist step by step, with direct links to each action.
