The Dashboard is the visual interface for workspace management at [driftless.icu](https://driftless.icu). It is not required — the CLI is fully functional as a standalone tool — but it provides visual context, team-wide visibility, and point-and-click management of your entire ecosystem.

## Authentication

The dashboard is protected by **Clerk** authentication. Sign in with your organization account. Your workspace is automatically resolved from your Clerk organization membership.

## Navigation

The sidebar provides access to every section of the dashboard:

| Section | Pages |
|---|---|
| **Control** | Ecosystem — workspace health, repos, setup checklist |
| **Repo Context** | Context browser, Topic Graph, PR Activity, Architecture, Activity log |
| **Integration** | Agents & CLI setup, Settings |
