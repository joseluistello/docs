The Driftless CLI is the primary way to manage context topics, sync your workspace, and connect AI agents to your codebase. You install it globally via npm and authenticate once with an API key from the dashboard.

## Requirements

- Node.js 18 or later
- npm 7 or later
- A Driftless account and API key

## Install

Install the CLI globally so the `driftless` command is available in any directory.

```bash
npm install -g @driftless-sh/cli
```

Current version: **v0.2.1** — available as `@driftless-sh/cli` on npm.

## Authenticate

After installing, log in with your API key. You can find your key in the Driftless dashboard under **Settings → API Keys**.

```bash
driftless login
```

To pass the key non-interactively (useful in CI):

```bash
driftless login --key drift_your_key_here
```

## Verify your installation

Run `driftless doctor` to confirm the CLI can reach the API, detect your git repository, and locate your workspace.

```bash
driftless doctor
```

A healthy output looks like:

```text
✔ auth       Authenticated as your@email.com
✔ api        Connected to https://api.driftless.icu/api/v1
✔ git        Git repository detected
✔ workspace  Workspace resolved
```

If any check fails, the output includes a short explanation and a suggested fix.

## Environment variables

You can configure the CLI through environment variables instead of interactive prompts. These are particularly useful in CI pipelines and Docker environments.

| Variable | Description | Default |
|---|---|---|
| `DRIFTLESS_API_KEY` | API key for authentication | — |
| `DRIFTLESS_API_URL` | Override the API base URL | `https://api.driftless.icu/api/v1` |

<Tip>
In CI, set `DRIFTLESS_API_KEY` as a secret environment variable rather than passing `--key` inline. The CLI reads this variable automatically, so you can run commands like `driftless sync` or `driftless context load` without any additional flags.
</Tip>

## Next steps

Once installed and authenticated, initialize Driftless in your repository:

```bash
driftless init
```

This scans your repo, uploads a structural baseline, and installs the AGENTS.md skill so AI agents know how to pull and push context. See [CLI commands](/cli/commands) for the full reference.
