## `driftless sync`

Pull what your team changed since you last looked. Runs 4 parallel API calls to surface:

- **Stale topics** — topics whose anchored code has changed since the topic was last updated
- **Suggested topics** — auto-generated topics pending review
- **Recent PR activity** — team PR activity surfaced via the GitHub App integration
- **Repo metadata** — tracked branches and repo-level settings

```bash
driftless sync
driftless sync --json
```

| Flag | Description |
|---|---|
| `--json` | Machine-readable output |

<Tip>
  **Run this first in any session.** `driftless sync` is the fastest way to catch up on what changed while you were away.
</Tip>

---

## `driftless branches`

View your currently tracked branches. The default branch is always auto-tracked.

```bash
driftless branches
driftless branches --json
```

| Flag | Description |
|---|---|
| `--json` | Machine-readable output |

---

## `driftless branches add`

Add a branch to the tracked list. Pushes to tracked branches trigger drift detection.

```bash
driftless branches add staging
```

The default branch is always tracked. Adding it explicitly is a no-op. Duplicate additions are deduplicated.

---

## `driftless branches rm`

Stop tracking a branch. The default branch **cannot** be removed.

```bash
driftless branches rm staging
```
