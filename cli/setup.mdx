## `driftless init`

Scans the repo, uploads a baseline, and installs the agent skill. Runs as a 9-phase pipeline:

1. Validates that the directory is a git repo
2. Resolves the workspace via `/me`
3. Runs the local scanner
4. Registers the repo in Driftless Cloud
5. Uploads the baseline snapshot
6. Uploads components (chunked if >2000)
7. Generates smart watchers (if `--suggest`)
8. Detects existing docs (`AGENTS.md`, `ARCHITECTURE.md`, etc.)
9. Installs the agent skill in `CLAUDE.md` and `AGENTS.md`

```bash
driftless init --src apps/api --framework nestjs --suggest
```

| Flag | Description |
|---|---|
| `--src <path>` | Monorepo subdirectory to scan |
| `--framework <nestjs\|nextjs\|react\|other>` | Override auto-detection |
| `--suggest` | Auto-generate context topics from detected patterns |

<Tip>
  `--suggest` is off by default. Enable it to let Driftless propose context topics based on the code it finds.
</Tip>

<Warning>
  **Large files are skipped.** Any file over 1.5 MB is excluded from the scan. If 0 components are found, Driftless prints framework-aware guidance to help you debug.
</Warning>

## `driftless login`

Authenticate the CLI with your API key.

```bash
driftless login
```

| Flag | Description |
|---|---|
| `--key <api-key>` | Non-interactive login (key must start with `drift_`) |
| `--url <url>` | Override API URL |

Without `--key`, the command opens your browser to the Driftless dashboard where you can copy your API key.

## `driftless doctor`

Runs 8 health checks against your setup:

1. API key present
2. API reachable
3. Git remote configured
4. Workspace resolved
5. Repo linked
6. Baseline exists
7. `AGENTS.md` has Driftless block
8. GitHub App installed

```bash
driftless doctor
driftless doctor --json
```

| Flag | Description |
|---|---|
| `--json` | Machine-readable output |

Exits with code `1` if any check fails — suitable for CI gating.

## `driftless install-skill`

Installs the Driftless agent skill into the current repo.

- Downloads `SKILL.md` and references from the GitHub mirror to `.driftless/`
- Writes or updates `CLAUDE.md` with a `@.driftless/skill.md` reference
- Writes the managed block in `AGENTS.md` between `<!-- driftless:start -->` and `<!-- driftless:end -->`

```bash
driftless install-skill
```

<Note>
  **Self-healing.** Re-running `install-skill` replaces the managed block content in `AGENTS.md`, keeping older agents up to date. This is called automatically by `driftless init`.
</Note>
